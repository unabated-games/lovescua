# Upstream method migration audit

Generated by `python3 scua/compatibility_audit.py` from the Lua registration tables in this fork. Lists **1090 registered entries in 73 wrapper files**, including legacy aliases and internal functions. Inherited methods are listed at their declaring wrapper. This is a migration index, not a compatibility percentage.

**Named/Adapted** identify a registered destination; signatures and defaults can differ. **Record** names source-reviewed fields with implementation links; the generator checks those keys in the named function. This is not a behavioral parity certificate. **Replacement/Host-owned/Excluded** describe deliberate boundaries. **Gap** is an exposed migration gap, not completed conversion. Actors replace Lua thread/channel patterns. Class-wide Family fallbacks are disabled: an unreviewed method is a Gap. No Lua source compatibility is promised.
